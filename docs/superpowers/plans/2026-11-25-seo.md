**Goal:** LUMEN(https://lumen-showroom.vercel.app)에 사이트맵 · robots · 페이지별 메타(정본 주소 · 설명 · 공유 미리보기) · 상품 구조화 데이터 · `llms.txt` 를 넣고, 장바구니 · 결제 · 주문 · 로그인 화면과 Vercel 미리보기 배포는 검색에서 뺀다.

**Architecture:** Next 16 App Router(서버 렌더 + Vercel). 주소 · 색인 정책은 작은 순수 모듈(`src/seo/`)에 두고 Vitest 로 검사한다. robots · sitemap · llms.txt 는 `src/app` 의 메타데이터 파일 / 라우트, JSON-LD 는 서버 컴포넌트가 `<script type="application/ld+json">` 으로 그린다. 상품 값은 모두 `@/catalog/query` 에서 온다(화면과 같은 출처).

**Tech Stack:** Next.js 16 (App Router), TypeScript, Vitest, Playwright, Vercel

## Global Constraints

- 정본 주소 `SITE_URL = "https://lumen-showroom.vercel.app"` 상수 하나(`src/seo/site.ts`)만 쓴다.
- 구조화 데이터 · 메타에는 화면에 보이는 값만(설계 §2). 가격은 `priceKRW`, 통화 `KRW`. 상품 사진이 없으므로(3D 모델만) Product `image` 는 넣지 않는다.
- 이 쇼핑몰은 포트폴리오 데모이며 결제는 토스페이먼츠 **테스트 결제**만 된다. `llms.txt` 와 사이트 설명에서 실제 판매처럼 쓰지 않는다.
- 비공개 화면(`/cart`, `/checkout`, `/checkout/**`, `/orders`, `/orders/**`, `/login`)은 메타 `robots: { index: false, follow: false }` 로 뺀다. robots.txt 로 막지 않는다(막으면 크롤러가 noindex 를 못 읽어 오히려 색인이 남을 수 있다 — 구글 문서). robots.txt 는 `/api/` 만 막는다.
- Vercel 미리보기(`VERCEL_ENV === "preview"`)는 robots.txt 전체 차단 + 모든 페이지 noindex. 로컬(`VERCEL_ENV` 없음)과 운영은 색인 허용.
- AI 크롤러(OAI-SearchBot · ChatGPT-User · PerplexityBot · ClaudeBot · Google-Extended · GPTBot)는 막지 않는다.
- JSON-LD 는 `JSON.stringify(x).replace(/</g, "\\u003c")`. 새 클라이언트 JS 금지(3D 쇼룸 성능을 공들여 맞춘 사이트).
- 문구는 사람이 쓴 문체, 사실만. 커밋 · PR 본문은 면접관이 읽는다(제목 + 왜 본문, 한국어 `feat:`/`docs:` 형식 — 이 저장소 기존 커밋을 따른다), 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. 머지는 소유자가 시킬 때만.
- 검사: `npm run check`(lint · tsc · 단위), `npm run test:e2e`(빌드 후 3100 포트). Next 16 문서는 `node_modules/next/dist/docs/`(AGENTS.md).

## Review Focus

- **카테고리 필터 주소:** `/products?category=…` 가 정본 주소를 따로 갖거나 사이트맵에 들어가면 중복이 된다 → 정본은 `/products`, 사이트맵에 쿼리 주소 없음(Task 1 · 2 검사).
- **없는 상품 주소:** `/products/없는-slug` 는 404 이고 JSON-LD 가 없어야 한다 → Task 3 e2e.
- **가격 불일치:** JSON-LD `offers.price` 가 화면 가격과 다르면 구조화 데이터 스팸 → Task 3 e2e 가 화면 텍스트와 대조.
- **비공개 화면 누락:** 새 비공개 하위 경로(`/orders/[id]/complete`, `/checkout/fail`)도 noindex → Task 2 e2e 가 하위 경로까지.
- **미리보기 판정 오류:** `VERCEL_ENV` 가 `production` 인데 noindex 가 붙으면 운영이 검색에서 사라진다 → Task 1 단위 검사가 세 값(production · preview · 없음)을 모두.
