# 1차 성능 측정 (2026-11-02)

## 측정 방법

- **fps** — 쇼룸(`/`)을 처음부터 끝까지 41단계로 스크롤하며 0.5초마다 디버그 HUD(`?debug`)의 fps 를 읽는다.
  스크립트: `.superpowers/measure.mjs` (로컬 전용). 프로덕션 빌드(`next start`)
- **고정 vs 자동** — `?tier=2&adaptive=off` (최고 품질 고정) / 쿼리 없음 (GPU 판정 + 실행 중 조절)
- **첫 화면** — Lighthouse 12, 모바일 프리셋(시뮬레이션 4G · CPU 4배 감속)

### ⚠️ 아직 못 잰 것 — 목표 "저사양 노트북·중급 폰 30fps 이상"
M1 은 저사양이 아니고, CPU 감속은 GPU 부하를 흉내 내지 못한다. **실제 저사양 노트북과 휴대폰에서 같은 방법으로 재야 한다.**
배포 URL 에 `?debug` 를 붙여 쇼룸을 끝까지 내리며 HUD 를 보면 된다. 기기명과 함께 아래 표에 채운다.
